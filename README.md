# מנהל הקבצים X

מנהל קבצים לאנדרואיד: מהיר, בהיר ונקי, מותאם לעברית (מימין לשמאל). עובד בלי אינטרנט.

## הורדה
את קובץ ה-APK מורידים מדף ה-[Releases](../../releases/latest).

## שתי גרסאות
- **מנהל הקבצים X**: הגרסה המלאה
- **מנהל הקבצים X ללא וידאו**: אין בה צפייה בסרטונים (גם לא באפליקציות אחרות דרכה) ואין בה התקנת אפליקציות (בלי הרשאת התקנה). היא מותקנת בנפרד ויכולה לעבוד לצד הגרסה המלאה. בונים אותה עם `build.ps1 -Variant lite`

## מה יש בו
- **מסך בית עם אריחים:** אחסון פנימי, כרטיס SD, הורדות, תמונות, שמע, וידאו, מסמכים, אפליקציות, קבצים חדשים, ארכיונים, קבצים גדולים, סל מיחזור וניתוח אחסון
- **תפריט צד:** אחסון, ספריות, מועדפים, היסטוריה וכלים
- **רשימת קבצים:** שורת נתיב עם כפתור בית, אחוז השימוש באחסון, תצוגת רשימה או רשת, מיון, וקבצים נסתרים
- **פעולות על קבצים:** העתקה, העברה, שינוי שם, מחיקה לסל המיחזור, דחיסה וחילוץ ZIP, שיתוף, פרטים, סימניות, קיצור דרך במסך הבית, הסתרה ו"פתח כ…"
- **בחירה מרובה:** בחירת הכל ובחירת טווח
- **חיפוש:** מיידי בכל הקבצים, וגם בתוך תיקיה ובתיקיות המשנה שלה
- **אפליקציות מובנות:** מציג תמונות (זום והחלקה), נגן וידאו, נגן מוזיקה ועורך טקסט
- **ניתוח אחסון:** מה תופס הכי הרבה מקום, עם חלוקה לפי סוג קובץ

## בנייה
הפרויקט כתוב ב-Java בלי ספריות חיצוניות ובלי Gradle. הבנייה נעשית עם `build.ps1`, דרך aapt2, javac, d8 ו-apksigner.
דרישות: Android SDK (platform 34, build-tools) ו-JDK 17.

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```
